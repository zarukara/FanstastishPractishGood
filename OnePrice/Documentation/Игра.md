# One Price — мини-симулятор кофейни

Стартовая сцена: `Assets/_Presentation/Scenes/CoffeeShopGame.unity`.
Откройте её в Unity 6000.3.8f1 и нажмите Play. Сцена уже включена в Build Settings.
Исходный изменённый прототип `CoffeeShop.unity` сохранён отдельно; для сдачи используется CoffeeShopGame.

## Игровой цикл

В главном меню выберите «Открыть кофейню». Справа на чеке показаны напиток, состав,
время ожидания и награда. Выберите ингредиенты внизу, нажмите «Приготовить», дождитесь
готовности и нажмите «Выдать». Порядок ингредиентов не важен, количество каждого важно.
До приготовления можно убрать последний ингредиент. Во время приготовления и после
его завершения состав зафиксирован до выдачи или истечения заказа.

Смена длится 150 секунд, цель — 120 монет выручки, начальная репутация — 100.
Ошибка стоит 25 репутации, опоздание — 20. По достижении цели сразу наступает победа.
При нулевой репутации или истечении времени без достижения цели — поражение.
Кнопка «Пауза» и Escape останавливают все три таймера. Настройки, открытые из паузы,
возвращают в паузу. Выход в меню отменяет текущий заказ и напиток.

Выручка начинается с нуля каждую смену. Кошелёк накапливает награды между сменами
и запусками, даже если смена закончилась поражением. Лучшие выручка и число заказов
обновляются после каждой успешной выдачи. Незавершённые заказы не сохраняются.

## Улучшения и настройки

На экране улучшений доступны кофемашина, авторская подача и уютный зал:
скорость приготовления, награда и время ожидания соответственно.
У каждого улучшения три уровня, цены 45 / 90 / 150, прирост +25% за уровень.
Скорость — множитель: длительность = базовая длительность / (1 + бонус скорости).
Покупки доступны между сменами, недоступные по цене и максимальному уровню кнопки отключены.
Громкость влияет на звуки кнопок и результата выдачи. Полноэкранный режим работает в
Windows-плеере; окно Game в редакторе не является полноэкранным плеером.

Сохранение: один JSON в PlayerPrefs с ключом `OnePrice.CoffeeShop.Save.v1`.
Тесты используют память либо уникальный тестовый ключ и не меняют игровой прогресс.
Не удаляйте все PlayerPrefs ради тестирования.

## Ассеты и архитектура

- `Configs/DayConfig_Main.asset` — длительность смены, цель, репутация, штрафы, приготовление.
- `Configs/Recipes`, `Configs/Ingredients`, `Configs/RecipeCatalog_Main.asset` — существующие рецепты и ингредиенты.
- `Configs/Upgrades`, `Configs/UpgradeCatalog_Main.asset` — цены, эффекты и стабильные идентификаторы покупок.
- `Prefab/IngredientButton_Game.prefab` и `Prefab/UpgradeCard.prefab` — шаблоны динамических кнопок.
- `Sprites/Cafe` и `Sprites/UI` — исходный визуальный набор, отдельные слои сцены.
- `Fonts/CoffeeShop_Cyrillic.asset` — отдельный шрифт с кириллицей.
- `Audio` — короткие синтезированные звуки, созданные специально для игры.

Все пути ассетов выше отсчитываются от `Assets/_Presentation`.
Все наши C#-скрипты находятся в `Assets/_Source`.
`Bootstrapper : LifetimeScope` — единственная точка сборки VContainer.
GameSession координирует смену; OrderService и DrinkPreparationService сохраняют свои
обязанности; UpgradeService проверяет покупки; SaveService сохраняет завершённые
транзакции. Presenter передаёт нажатия сервисам и отображает состояние.
Подписки снимаются при уничтожении контейнера.

Чтобы добавить рецепт, создайте RecipeConfig через Create → Coffee Shop → Recipe,
задайте минимум два ингредиента и добавьте его в RecipeCatalog_Main.
Новые ингредиенты из каталога автоматически получают кнопки. Колонки сетки — три;
текущие шесть ингредиентов занимают две строки. При значительном расширении каталога
потребуется расширить область сетки или добавить прокрутку.

## Проверка и сборка

Закройте редактор этого проекта перед запуском PowerShell:

```powershell
.\Tools\Verify-Game.ps1 -Build
```

Результаты: `Logs/editmode-results.xml`, журналы в `Logs`,
снимки интеграционного теста в `Logs/Screenshots`,
Windows-билд в `Builds/Windows-DX11/OnePrice.exe`. Каталоги Logs и Builds исключены из Git.

Unity Test Runner → EditMode запускает те же проверки, включая переход в Play Mode
и работу реальной сцены через кнопки с проверкой UI-raycast.
Меню Coffee Shop → Build Windows собирает плеер.
Меню Coffee Shop → Create or rebuild finished scene предназначено только для
намеренной пересборки макета: оно перезаписывает CoffeeShopGame и два игровых префаба,
но сохраняет текущие значения существующих конфигов.
Для обычного запуска пересоздавать сцену не требуется.

Перед пересдачей запустите Windows-билд на целевом компьютере, проверьте слышимость
звуков и удобство кнопок при выбранном разрешении.
