# Проверка One Price — 4 октября 2026

Unity: **6000.3.8f1**. Стартовая сцена: `Assets/_Presentation/Scenes/CoffeeShopGame.unity`.

## Выполнено

- Реальная компиляция игровых, редакторских и тестовых сборок Unity без ошибок C#.
- **17/17 тестов пройдено** в Unity Test Runner. Итоговый XML сохранён рядом с этим отчётом.
- Проверка сравнения рецептов без зависимости от порядка, с учётом повторов.
- Правильный заказ, однократная награда, неверный состав, отдельный штраф за ожидание,
  истечение заказа при приготовлении и очистка напитка.
- Блокировка изменения состава при приготовлении, удаление последнего ингредиента,
  защита действий вне смены, очистка при выходе в меню.
- Остановка времени дня, заказа и приготовления на паузе и в настройках из паузы.
- Победа по выручке, поражение по времени и репутации, отдельный кошелёк между сменами.
- Недостаточный баланс, предел уровня, покупка каждого типа улучшения и влияние всех
  трёх эффектов на приготовление, награду и ожидание.
- Сохранение и загрузка баланса, покупок, рекордов, громкости и полноэкранного флага;
  обработка повреждённого JSON и некорректных отрицательных значений.
- Реальная запись/чтение PlayerPrefs с изолированным тестовым ключом.
- Полный сценарий сохранённой сцены в Play Mode: меню → настройки → день →
  кнопки ингредиентов → приготовление → пауза → выдача → ошибка → опоздание →
  победа → покупка → повторная загрузка сцены → проверка сохранённого прогресса →
  проигрыш → меню.
- Для ключевых кнопок интеграционный тест проверяет, что UI-raycast попадает именно
  в кнопку, а не в декоративное изображение. Снимки экранов осмотрены; исправлены
  растяжение скруглений кнопок и обрезанное описание улучшения.

## Особенности среды

Полный интеграционный UI-тест запускается с рендерингом, без `-batchmode`:
в пакетном режиме Unity не отрисовывает Game View и часть UI-raycast не готова.
`Tools/Verify-Game.ps1` учитывает это. Создание сцены и сборка работают в batchmode.

Первый Windows-плеер на автоматическом DirectX 12 завершился с нативным сбоем
в D3D12Core. Этот сбой не был ошибкой C# в игре. Тот же плеер запущен с DirectX 11:
в журнале подтверждён D3D11, процесс продолжал работать без исключений.
Поэтому в финальных настройках Windows зафиксирован DirectX 11.

Управление игровым окном через Computer Use было остановлено пользователем
клавишей Esc. После этого автоматические действия в окне не выполнялись.

## Осталось проверить вручную

- В финальном Windows-плеере: физические клики, слышимость изменения громкости
  и переключение полного экрана.
- Закрыть и повторно открыть **процесс Windows-плеера** после заказа и покупки:
  кошелёк, улучшение и рекорд должны сохраниться. В автоматике уже проверены
  PlayerPrefs и перезагрузка сцены, но не этот полный пользовательский сценарий.
- Удобство чтения и нажатий на целевом компьютере при 1280×720 и 1920×1080.

Финальный плеер: `Builds/Windows-DX11/OnePrice.exe`.
Архив для переноса: `Builds/OnePrice-Windows.zip`. Распаковывать целиком:
папка OnePrice_Data и UnityPlayer.dll должны находиться рядом с exe.

Ваш исходный изменённый CoffeeShop.unity и исходный TMP fallback не
перезаписывались при сборке нового интерфейса. Ветки и коммиты не изменялись.
